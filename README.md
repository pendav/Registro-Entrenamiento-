# Mi registro de entrenamiento (React + TypeScript + Vite)

```bash
npm install
npm run dev        # desarrollo en http://localhost:5173
npm run build      # genera la carpeta dist/
npm run preview    # prueba local del build
```

Datos: IndexedDB (Dexie), tablas `entries` y `library`, guardadas en el navegador.
Despliegue gratis: sube la carpeta `dist/` a Netlify Drop, o publícala con GitHub Pages / Cloudflare Pages.
